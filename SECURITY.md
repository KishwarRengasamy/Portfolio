# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| main    | ✅ Yes    |

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public GitHub issue**.

Instead, report it privately via email:

📧 **kishwarrengasamy216@gmail.com**

Include the following in your report:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Potential impact assessment
- Any suggested fix (optional but appreciated)

You will receive a response within **48 hours**. I take security seriously and will work to address valid reports promptly.

---

## Security Notes for Contributors

- **Never commit `.env` files** — they are gitignored for a reason.
- **EmailJS public keys** are restricted to allowed origins in the EmailJS dashboard.
- No backend server-side secrets are stored in this repository.
